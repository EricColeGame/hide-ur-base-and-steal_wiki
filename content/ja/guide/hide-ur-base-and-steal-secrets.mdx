## 基本ゲームシステム：拠点とレイドの仕組み

高度なテクニックを学ぶ前に、突然の全ロストを防ぐための基本ループを理解しておきましょう。全プレイヤーは、拠点への入口となるポータルを設置する能力を持った状態でワールドに出現します。このマーカーの上に立つと、プライベートな拠点内部へ瞬時にテレポートします。

```
[メインマップ：オープンワールド]
       │
       ▼ (秘密のポータルマーカーを設置)
[隠された拠点の入口]
       │
       ▼ (マーカーに乗って移動)
[プライベートタイクーン内部] ──> ペットを購入 ──> 現金を生成 ──> 拠点を強化
```

ペットは経済成長の要です。拠点の内部に配置されている限り、時間経過とともに自動でゲーム内通貨を稼ぎ出します。スリルが生じるのは、他のプレイヤーを偵察するために拠点を離れた瞬間です。もし地上にあるマーカーを敵に見つかると、わずか数秒で侵入され、貴重なペットを強奪されてしまいます。

### ゲームプレイループの概要

| フェーズ | 主な目的 | 主なリスク | ベストプラクティス |
| :--- | :--- | :--- | :--- |
| **設置** | 人目につかない場所にポータルマーカーを配置 | 通りすがりの偵察者に見つかる | 環境オブジェクトを活用して入口をカモフラージュする |
| **生成** | 拠点でペットを購入・配置して収益化 | 機敏な泥棒に高ティアのペットを盗まれる | 利益をこまめに拠点のアップグレードへ再投資する |
| **偵察** | マップを探索して敵のマーカーを探す | 自拠点のマーカーを長時間無防備にする | 死角や不自然な地形ジオメトリを重点的に確認する |
| **潜入** | 敵の拠点に侵入してペットを略奪 | 現場を押さえられる、または逆レイドを受ける | 最も価値の高いペットを最優先で回収し、素早く脱出する |

## 拠点を隠すための最強配置スポット＆シークレット

理想的な隠れ場所を見つけられるかどうかで、不労所得を順調に積み上げられるか、ログインした際に部屋が空っぽになっているかの明暗が分かれます。初心者が最もやりがちなミスは、スポーンエリアのすぐ外や、誰もが通るメインルート沿いにマーカーを置いてしまうことです。

実証済みの **hide ur base and steal secrets** を応用するなら、カメラアングル、オブジェクトの当たり判定、生い茂る茂みを活用し、周囲の地形にポータルを完璧に同化させる必要があります。

### 隠れ場所ティアリスト

| スポットタイプ | 隠蔽度 | アクセスのしやすさ | 推奨シチュエーション |
| :--- | :--- | :--- | :--- |
| **茂みの中** | 高 (Aティア) | 素早い | 序盤の低コストな現金稼ぎ（濃い草むらの奥） |
| **崖の裂け目** | 非常に高 (Sティア) | 普通 | 高価なレアペットを保管する中盤～終盤 |
| **マップ端の死角** | 中 (Bティア) | 遅い | 人通りが皆無の場所での長時間放置（AFK）ファーム |
| **建物の屋根・梁** | 高 (Aティア) | 遅い（パルクールが必要） | 索敵プレイヤーが徘徊する危険度の高いサーバー |
| **平地・開けた地面** | 極めて低 (Fティア) | 即時 | いかなる状況でも非推奨 |

### ポジショニングの鉄則
* **わかりやすい対称配置を避ける：** ランドマークや構造物のど真ん中にマーカーを置かないでください。経験豊富なプレイヤーは真っ先にそこを調べます。
* **影のスペースを活用する：** 暗い窪地や、大きく張り出した岩の下に置かれたマーカーは、視覚的に目立ちにくくなります。
* **プレイヤーのカメラ視線に合わせる：** 多くのプレイヤーは、やや見下ろす三人称視点カメラで走り回っています。垂直に切り立った段差のすぐ真下にマーカーを潜り込ませると、通常の視界スキャンから外れやすくなります。

## 敵のペットを効率的に偵察・略奪する方法

本当の富はレイド（略奪）狩りにあります。地道に初期ペットを購入し続けるよりも、果敢に偵察を行ってライバルの隠れ家を見つけ出す方がはるかに早く稼げます。敵のマーカーを見つけるには、忍耐力と「追い詰められたプレイヤーが無意識に隠しそうな場所」を予測する洞察力が必要です。

敵の隠れ場所を割り出してスマートに強盗を成功させるためには、以下の戦術ステップとあわせて [Game Rant's Roblox Coverage](https://gamerant.com/roblox/) などの最新ガイドも参考にしてください。

### 潜入戦略チェックリスト

| ステップ | アクション | 目的 | 戦術のヒント |
| :---: | :--- | :--- | :--- |
| **1** | **外周スキャン** | プレイヤーが密集するエリアを特定 | プレイヤーとの直接戦闘は避け、ステルス状態を維持する |
| **2** | **テクスチャ確認** | 不自然なインタラクティブマーカーを発見 | 地面のテクスチャに対して不自然な継ぎ目を探す |
| **3** | **拠点侵入** | 敵のマーカーを踏んで中へ入る | 自拠点を施錠するか、貴重品を回収した状態で実行する |
| **4** | **価値の見極め** | 最も収益性の高いペットを最優先で回収 | インベントリ容量が少ない場合、初期ペットは無視する |
| **5** | **高速脱出** | 地上へ戻る | 盗んだペットを自拠点に保管するため、即座にダッシュする |

敵の拠点に侵入した際、最大の武器となるのは「スピード」です。コミュニティのデータによると、敵拠点の内部で物色に15秒以上費やしたプレイヤーは、現場を押さえられるか、留守中の自拠点を逆レイプされる確率が3倍に跳ね上がることが分かっています。

## ペット経済：放置現金の投資と最大化

ペットは『Hide ur Base and Steal』における進捗の心臓部です。ペットが継続的に利益を生み出してくれなければ、上位の拠点拡張やセキュリティのアップグレードを行うことはできません。ペットのインベントリ管理には、リスクとリターンのバランスが求められます。価値の高いペットを溜め込みすぎると格好の標的となり、低ティアのペットばかりでは成長スピードが停滞してしまいます。

### ペットティアの進行概要

| ティア | 現金倍率 | 基本コスト | 盗難リスク | 推奨アクション |
| :--- | :--- | :--- | :--- | :--- |
| **コモン** | 1.0倍 | 低 | 極めて低 | 序盤の枠埋め用。速やかに上位種へ入れ替える |
| **レア** | 2.5倍 | 普通 | 低 | 中盤の資金調達を支える頼もしい主力 |
| **エピック** | 5.0倍 | 高 | 中 | 設置する前に拠点の安全な隠し場所を確保する |
| **レジェンダリー** | 12.0倍 | 非常に高 | 高 | 常に監視できない無防備な拠点には絶対に置かない |
| **ミシック / シークレット** | 25.0倍以上 | 極めて高 | 最大 | 連携が取れるチームセッション時に運用するのがベスト |

**hide ur base and steal secrets** を極める重要なポイントの一つが、ペットの戦略的なローテーションです。もし自拠点のマーカー付近を徘徊する高レベルの偵察者を見かけたら、被害を受ける前に稼ぎ頭のペットを一時的に退避させるか、マップの別セクターへ入口マーカーを移設しましょう。

## 上級防衛テクニック：レイドから拠点を守り抜く

どれほど優れた攻撃力を持っていても、自分の金庫が20分おきに略奪されていては意味がありません。拠点を守り抜くには、心理的な誘導とスマートな立ち回りの組み合わせが必要です。

### 防衛戦略の比較

| 防衛戦略 | 実行の難易度 | 効果 | リソースコスト |
| :--- | :--- | :--- | :--- |
| **デコイマーカー（おとり）** | 普通 | 高 | ゲーム内通貨（中） |
| **こまめな拠点移設** | 簡単 | 非常に高 | なし |
| **チーム交代監視** | 難しい | ほぼ鉄壁 | アクティブなフレンドが必要 |
| **角・隅の徹底活用** | 簡単 | 普通 | なし |

### プロが実践する防衛のコツ
* **レイド成功後は必ず移設する：** 近隣のプレイヤーから略奪に成功した場合、必ず報復の偵察が行われます。帰還したら直ちにまったく別のエリアへマーカーを移動させましょう。
* **拠点の現金を溜め込まない：** 金庫内に未回収の現金を大量に放置してはいけません。稼いだお金はすぐにペットの強化やキャラクターの移動速度ブーストに使いましょう。
* **プレイヤーのリスポーン地点を注視する：** プレイヤーがどこでリスポーンしているかを把握しましょう。北の丘陵地帯で小競り合いが始まったら、拠点のマーカーは南の海岸線へ退避させるのが安全です。

これらの **hide ur base and steal secrets** を駆使することで、ライバルたちを翻弄しながら、莫大な富を生み出す強大な帝国を築き上げることができます。

## よくある質問（FAQ）

### ソロプレイヤーに最もおすすめの hide ur base and steal secrets は何ですか？
ソロプレイヤーにとって最強の戦略は、マップ端にある「崖の裂け目」や垂直の段差を利用することです。通常の三人称カメラの視野角より下にマーカーを配置することで、通りすがりのスカウトに入口を発見されるリスクを大幅に下げられます。近くに他のプレイヤーが居座っている場合は、必ずマーカーを別の場所へ移設してください。

### オフライン中にペットを盗まれることはありますか？
標準的なサーバー設定では、サーバーから退出すると拠点も消去（デスポーン）されるため、オフライン中にペットが盗まれることはありません。ただし、オンラインでマップを探索している間は、拠点のマーカーを発見したすべてのプレイヤーに対してペットが無防備な状態になります。

### 『Hide ur Base and Steal』の新コードはどのくらいの頻度で追加されますか？
新しいコードは通常、大型アップデート、バグ修正、コミュニティのマイルストーン（お気に入り数やいいね数の目標達成など）に合わせてリリースされます。新しい引き換えコードが追加された際に通知を受け取るには、公式の Sutik x Tommy 開発者グループに参加するのが最も確実な方法です。
