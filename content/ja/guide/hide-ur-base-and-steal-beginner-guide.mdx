## 基本ゲームシステム：タイクーンの仕組み

このゲームの根底にあるのは、「隠し入り口を作る」「ペットによる経済を構築する」「ライバルの拠点を襲撃する」というハイリスク・ハイリターンなゲームプレイサイクルです。

サーバーに参加すると、入り口マーカー（Entrance Marker）ツールが付与されます。このポータルを地面に設置すると、自分専用の地下金庫へと直接つながるアクセストンネルが生成されます。内部では、ペットたちが自動的に不労所得（キャッシュ）を生み出してくれます。しかし、入り口マーカーは地上ワールドから視認可能です。鋭いプレイヤーにマーカーを見つけられて中に入られると、ペットの飼育エリアに直接侵入され、コレクションを持ち去られてしまいます。

```
秘密マーカーを設置 ➔ 地下金庫へアクセス ➔ 収益ペットを購入 ➔ 敵拠点を捜索 ➔ 略奪＆防衛
```

コアとなるサイクルを理解しやすくするために、主なゲームプレイの要素とそのバランスを以下にまとめました：

| ゲームプレイ要素 | 主な目的 | 主なリスク | 報酬 / 成果 |
| :--- | :--- | :--- | :--- |
| **拠点の隠蔽** | ポータルマーカーをカモフラージュする | 探索中のプレイヤーに発見される | 安全な不労所得の生成 |
| **ペットエコノミー** | より高ティアの仲間を購入する | 侵入者に高価な資産を奪われる | 1秒あたりのキャッシュ（CPS）増加 |
| **偵察と潜入** | マップ上で敵のマーカーを探す | 待ち伏せや逆襲に遭う | 高額ペットを無料で強奪できる |
| **アクティブ防衛** | 周囲を監視し入り口を警備する | 警戒で立ち往生し偵察時間を浪費する | 自分の経済基盤を維持・保護する |

地下金庫の拡張と地上での偵察のバランスをうまく取ることが、サーバーのリーダーボード上位に登りつめるための最大の秘訣です。

## 拠点入り口の配置と隠し方

拠点のマーカーは、あなたにとって最大の弱点です。デフォルトのスポーンエリア付近の開けた場所に放置することは、自ら破滅を招くようなものです。意表を突く隠し場所を見つけるには、プレイヤーのカメラアングルや主要な移動ルートを理解する必要があります。

### 地形環境の利点を活かす

大半のプレイヤーは、目印となるランドマーク、ショップ、あるいは高台へ向かってまっすぐダッシュします。狙い目は「通過ゾーン」— プレイヤーが足元を意識して見下ろさずに通り過ぎるようなエリアです。

| 地形タイプ | カモフラージュ評価 | メリット | デメリット |
| :--- | :--- | :--- | :--- |
| **生い茂る草むら / 茂み** | 高 (4.5/5) | カメラの直接的な射線を遮る | 上級者にとっては真っ先に探す定番スポット |
| **崖の裂け目・くぼみ** | 非常に高 (4.8/5) | 発見するにはカメラを不自然に傾ける必要がある | 緊急時に素早く飛び込んで戻りにくい |
| **影の落ちる場所** | 中 (3/5) | 暗いマーカーがテクスチャに溶け込む | 光の加減が変わると輪郭が露出することがある |
| **建造物のオーバーハング** | 高 (4.2/5) | 上空からの索敵から保護される | 周辺の通行量がやや多い |
| **開けた平原** | 危険 (1/5) | 自分自身がアクセスしやすい | 数分以内に発見される |

### 戦略的配置のルール

1. **ショップの近くには絶対に置かない：** 中央ハブは最もプレイヤーの往来が激しい場所です。主要ショップからダッシュで行ける範囲に拠点を置くと、高確率ですぐに略奪されます。
2. **射線（ライン・オブ・サイト）を切る：** ポータルは必ずオブジェクト、岩、または傾斜の裏に設置してください。相手がカメラを意図的に回転させないとマーカーが画面に映らないように仕向けましょう。
3. **ランドマークを覚えておく：** 盗んだ獲物を抱えてプレッシャーの中逃げ帰るときに、自分自身が帰り道を見失ってしまうほど複雑に隠しすぎないよう注意しましょう。

## ペットと経済：不労所得を築く

ペットはあなたの帝国のエンジンです。ペットがいなければ、資金の蓄積は完全にストップしてしまいます。この **hide ur base and steal 初心者ガイド** に従う際は、最初の数セッションは見た目の豪華さよりも純粋な収益スピードを最優先してください。

ペットにはそれぞれ固有の「1秒あたりの獲得キャッシュ（CPS）」が設定されています。初期に得たキャッシュをすぐに拠点の拡張やより良いタマゴに再投資することで、収益は雪だるま式に増加します。

| ペットティア / タイプ | 基本コスト（キャッシュ） | 収益率（CPS） | 投資回収時間（ROI） | 推奨される役割 |
| :--- | :--- | :--- | :--- | :--- |
| **スターター ネコ / イヌ** | 無料 – $100 | $1 – $5/秒 | 即時 | 初期のタマゴ購入資金を稼ぐバッファー |
| **アンコモン生物** | $500 – $1,500 | $15 – $45/秒 | 約30～45秒 | 中盤への経済をつなぐ確実な架け橋 |
| **レアビースト** | $5,000 – $15,000 | $120 – $350/秒 | 約40～50秒 | 中盤におけるメインの収入源 |
| **エピックガーディアン** | $50,000以上 | $1,000以上/秒 | 約50～60秒 | 狙われやすい高価値ターゲット；厳重に保護必須 |
| **レジェンダリー / ミシック**| $250,000以上 | $5,000以上/秒 | 変動あり | 拠点を大きく牽引する主力パワーハウス |

*注：ゲーム内の価格および収益数値は、アップデートを通じて収集された一般的なバランス調整基準およびコミュニティの報告に基づいています。*

### 収益戦略：「分散と時間稼ぎ」アプローチ

最も稼ぎの良いペットを、入り口のハシゴのすぐ横のような無防備な場所にまとめて配置するのは絶対にやめましょう。レイアウトが許す限り、飼育スペースやペットの配置は金庫の最奥のコーナーに向けて配置してください。泥棒が侵入してきた際、盗みを行える時間は限られています。部屋の奥深くまで走らせることを強制すれば、現行犯で捕まえるチャンスが大幅に高まります。

## 略奪戦術：効率的に偵察し盗み出す方法

守るだけでは戦いの半分に過ぎません。進行スピードを一気に加速させるには、泥棒の技術をマスターする必要があります。ライバルプレイヤーを略奪すれば、自分の資金を1ドルも使わずに高価なペットを奪い取ることができます。

### ステップ・バイ・ステップの潜入シークエンス

体系化された手順に従うことで、強奪中に返り討ちに遭ったり閉じ込められたりするリスクを最小限に抑えることができます：

| ステップ | アクション | 目的 | 戦術的ヒント |
| :--- | :--- | :--- | :--- |
| **1. 地表の捜索** | 外周エリアをスキャン | 人目につかないマーカーを発見する | 中央部ではなくマップ境界に沿って移動する |
| **2. カメラ確認** | 3人称カメラを傾ける | 内部に持ち主がいるか確認する | 床越しにプレイヤーネームタグが見えないか探す |
| **3. 潜入** | マーカーの上に立つ | 標的の拠点へ静かに侵入する | すぐに高ティアの飼育エリアへ向かう |
| **4. 資産の持ち出し**| ターゲットのペットを回収 | 1秒あたりの価値を最大化する | 最もレアなオーラや高ティアのものを最優先で掴む |
| **5. 鮮やかな脱出** | ポータル出口へダッシュ | 安全な地上へと帰還する | 自分の拠点へ一直線に戻らない |

### 追跡者の振り切り方

相手のペットを掴むことに成功すると、移動速度がわずかに低下したり、被害者に犯行を目撃された場合に即座に追跡を受けたりすることがあります。絶対に自分の拠点の入り口に向かって直線的に逃げてはいけません。秘密のマーカーまで一直線に追跡されてしまえば、奪ったペットを取り返されるだけでなく、ついでに自分の拠点まで根こそぎ略奪されてしまいます。

新たに手に入れた資産を安全に確保するため、必ず人通りの多いランドマークや岩場などを経由して視界を遮る（射線を切る）迂回ルートを通ってから帰還しましょう。

## 初心者が知っておくべき必須のコツと避けるべきミス

この **hide ur base and steal 初心者ガイド** の締めくくりとして、プレイ開始からの数時間は以下の重要なルールを心に留めておいてください：

* **地上で放置（AFK）しない：** 入り口の近くにアバターを立たせたまま放置すると、周囲を捜索してくださいと言わんばかりの格好の目印になります。キーボードから離れる必要がある場合は、金庫の中に入るか、メインのスポーンゾーンで行いましょう。
* **拠点の防御アップグレードを怠らない：** 拠点のアップグレードや金庫のロックが購入可能になったら、すぐに購入してください。セキュリティ強化を後回しにしてペットばかり買っていると、拠点が他のプレイヤーにとって格好の獲物になるだけです。
* **リーダーボードをチェックする：** サーバーリストでプレイヤーの総資産に目を光らせておきましょう。上位のプレイヤーは高確率でエリートペットを所持しています。そうした熟練プレイヤーが地形のどこに消えていくかを突き止めることができれば、略奪によって一気にゲームを進めることができます。
* **襲撃されたら場所を変える：** 敵に拠点を荒らされた場合、その場所は完全に割れたと考えてください。マーカーを回収し、マップのまったく別のセクターに移動して、新たに拠点を構え直しましょう。

## よくある質問（FAQ）

### 新しいサーバーに入ったら、まず何をすべきですか？
マップ外周の目立たない、草木に覆われたエリアを見つけて拠点のマーカーを設置しましょう。その後、すぐに最初のスターターペットを購入し、周囲のプレイヤーの位置を偵察している間にもキャッシュが自動生成される状態を作ります。

### 他のプレイヤーにすべてのペットを一度に盗まれることはありますか？
基本的に、ゲームのバランス調整により侵入者が一度に持ち運べる資産の数には制限が設けられています。しかし、泥棒が邪魔されずに何度も往復した場合、金庫の中身を計画的に空にされてしまう可能性があります。だからこそ、本 **hide ur base and steal 初心者ガイド** で解説した積極的な防衛策を身につけることが極めて重要なのです。

### 拠点のマーカーが消えてしまったのはなぜですか？
マーカーが見当たらない場合、セッションが切断されたか、誤ってマーカーツールをインベントリに回収してしまった可能性があります。マーカーを再度地面に設置すれば、通常は蓄積したペットをリセットすることなく、保存されている金庫データが再び開きます。

### 盗んだペットを安全に自分の拠点へ持ち帰るにはどうすればいいですか？
追跡してくるプレイヤーの視界を遮り、隠したマーカーへ向かって大回りするルートを取り、素早く金庫に入ってアクティブな飼育エリアにペットを配置することで所有権を確定させます。
