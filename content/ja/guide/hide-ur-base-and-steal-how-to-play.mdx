## 基本システム：ゲームの仕組みを理解する

このゲームの本質は、拠点建設、放置収集、そしてステルス襲撃の融合です。ゲームプレイのサイクルは、隠蔽、経済拡大、日和見的な窃盗という相互依存する3つの柱で成り立っています。

```
[隠しマーカーを設置] ➔ [拠点構築＆ペット購入] ➔ [資金を自動生成] ➔ [敵のマーカーを索敵] ➔ [ペットを盗んで利益獲得]
```

### 2層構造のマップシステム

ゲームは2つの異なる空間で進行します：
1. **地上ワールド（Overworld）：** プレイヤーがリスポーンし、マーカーを探し、障害物を駆け回り、ショップを利用する共有のパブリック空間。
2. **地下拠点（Underground Base）：** 設置した入り口からのみアクセスできるプライベートな異次元空間。内部ではペットが不労所得を生み出し、各種アップグレードを購入できます。

もし他のプレイヤーが地上のマーカーを見つけると、直接その上に乗ってあなたの基地へ侵入し、反応する間もなくペットを略奪されてしまいます。

| コア要素 | 機能 | 戦略的重要度 |
| :--- | :--- | :--- |
| **入り口マーカー** | 自分（およびライバル）を地下拠点へテレポートする | 最重要：配置を誤ると即座にペットを失う |
| **基地内部** | 購入したペットや回収ポイントを配置する場所 | 中：アップグレードで床面積やペット上限が拡張 |
| **収益ペット** | 時間経過とともにコイン／キャッシュを自動生成 | 高：すべての進行、強化、装備の資金源 |
| **地上ワールド** | ライバルの拠点を捜索するための共有アリーナ | 高：積極的な索敵が素早い資源強奪につながる |

## ゲームの始め方：ステップバイステップの手引き

セッションに初めてロードされた瞬間から、タイムリミットは始まっています。他のプレイヤーはすでに草むらや丘、物陰をくまなく探し、生まれたばかりのポータルを狙っています。計画的なセットアップを行うことで、初期資金を略奪者に奪われるリスクを回避できます。

### 初心者向けセットアップ手順

| ステップ | 目標 | 主なアクション | プロのアドバイス |
| :---: | :--- | :--- | :--- |
| **1** | 場所の選定 | 中央のリスポーン地点からすぐに離れる。 | リスポーン付近の開けた野原や目立つ道は避ける。 |
| **2** | マーカー設置 | 複雑なオブジェクトの背後に入り口パッドを置く。 | 地形の起伏に合わせるか、影の中に隠す。 |
| **3** | 拠点へ入る | マーカーを踏んで地下の敷地へ移動する。 | 遠くからマーカーがはっきりと見えないか再確認する。 |
| **4** | 初期ペット購入 | 初期資金を使って最安のペットを購入する。 | ペットは数秒ごとに自動で収益を生み出す。 |
| **5** | 利益の保管 | 貯まったお金を回収し、安全に保管する。 | 大金を保管せず放置するのは絶対に避ける。 |
| **6** | ライバルの索敵 | 地上に戻り、敵のマーカーを探す。 | 不審な動きをしているプレイヤーの挙動に注目する。 |

**hide ur base and steal how to play**を極めるということは、入り口マーカーを最も価値ある秘密として扱うことを意味します。もし立ち止まっている姿や突然姿を消す瞬間を相手に見られれば、ポータルの場所は一瞬で特定されてしまいます。

## おすすめの拠点隠し場所とカモフラージュ戦術

拠点をどこに配置するかによって、ログインしたときに金庫が潤っているか、あるいは空っぽになっているかが決まります。マップ内には、巧妙に隠れるための小道具、植物、高台の段差、入り組んだ角が多数存在します。

### 配置場所の戦術的評価（ティアリスト）

| 配置場所のタイプ | カモフラージュ度 | アクセスの容易さ | リスク | おすすめ度 |
| :--- | :---: | :---: | :---: | :--- |
| **中央付近の障害物の裏** | D | 極めて高い | 致命的 | 完全非推奨。ライバルが最初に探す場所 |
| **開けた草地** | F | 最大 | 致命的 | 自滅行為。遠くからでも丸見え |
| **外周の崖の段差** | A | 中 | 低 | 優秀。到達にアスレチック（パルクール）が必要 |
| **生い茂った草木・木の下**| B+ | 高 | 中 | マッチ序盤の素早い設営に適している |
| **マップ端の過疎エリア** | S | 低 | 極めて低 | 最善の選択。端までパトロールする人は稀 |

```
高リスク区域：リスポーン中央、広い野原、メインの通路
安全区域：マップの四隅、エリア外スレスレの段差、密集した茂みの奥
```

### コミュニティ検証済みの隠蔽テクニック
* **視線をフェイクする：** 一方向に走り、他のプレイヤーが目をそらすのを待ってから引き返し、マーカーを設置します。プレイヤーの移動軌跡を追うことが、偵察者が新規拠点を特定する最も一般的な方法です。
* **風景に溶け込ませる：** 似た色や形の環境オブジェクトの近くにマーカーを置き、コントラストを最小限に抑えます。
* **こまめに拠点を移動する：** 隠れ家の周りを怪しいプレイヤーがうろつき始めたら、地面を詳しく調べられる前に、入り口を新しい場所へ移転させましょう。

## 襲撃と防衛：略奪のテクニック

攻撃と防衛は表裏一体です。ペットが地下で収益を生み出している間、ポータルを守るべきか、それとも敵を狩りに行くべきかの判断を迫られます。このバランス感覚を掴むことこそが、**hide ur base and steal how to play**の上級者になるための基本です。

### 敵基地の索敵方法

他プレイヤーの基地を見つけるには、忍耐と観察力が必要です。地上マップで突然消えたり、何もないところから現れたりするプレイヤーに注意を払いましょう。索敵時のポイントは以下の通りです：
1. 上級者が好んで隠れるマップの境界線を一周する。
2. 大きな岩、看板、装飾用ストラクチャーの死角を調べる。
3. 起伏のある地形で部分的に隠れたマーカーを見つけるため、カメラの角度を常に見下ろし気味にする。

### プレイスタイルの比較：防衛型 vs 襲撃型

| 指標 | パッシブ防衛型 | アグレッシブ襲撃型 | ハイブリッド戦術型 |
| :--- | :--- | :--- | :--- |
| **主な収入源** | 自身のペット生産 | 盗んだ高ティアペット | バランス型（生産＋襲撃） |
| **地上の滞在時間** | 10% - 20% | 80% - 90% | 40% - 50% |
| **リスクレベル** | 低 | 高 | 中 |
| **成長スピード** | 着実／遅い | 略奪の成功次第で爆発的 | 最適かつ安定的 |
| **プレイスキル上限** | 低 | 高 | 非常に高い |

敵の隠れ家への潜入に成功したら、最も収益性の高いペットを最優先で狙いましょう。持てるだけ掴んで速やかに脱出してください。基地の持ち主が侵入に気づいて戻り、迎撃してくる危険性があります。

## ペット経済と育成ルート

ペットはあなたの帝国の動力源です。ペットがいなければ、不労所得の流れは完全にストップしてしまいます。『Hide ur Base and Steal』の育成は、コストが指数関数的に増加する一方で収益も大幅に跳ね上がる標準的なアップグレード曲線に従います。

### ペットのティア別進行表

| ティア | 平均コスト | 秒間収益（CPS） | 投資回収期間 | 戦略的役割 |
| :---: | :--- | :--- | :--- | :--- |
| **ティア1（コモン）** | 100 - 500 | 2 - 10 / 秒 | 超高速（約1〜2分） | 序盤の立ち上げ用 |
| **ティア2（アンコモン）**| 1,000 - 5,000 | 25 - 120 / 秒 | 高速（約3〜5分） | 中盤への足がかり |
| **ティア3（レア）** | 10,000 - 50,000 | 300 - 1,500 / 秒 | 普通（約10分） | 襲撃者の主な標的 |
| **ティア4（エピック）** | 100,000以上 | 3,500以上 / 秒 | 長め | 終盤の主力を担う収入源 |
| **ティア5（レジェンダリー）**| 実績達成／イベント | 10,000以上 / 秒 | 変動 | 命がけで死守すべき存在 |

基地のペット配置数には上限があるため、低ティアのペットを抱え込み続けるのは非効率です。レア以上の高収益ペットが手に入り始めたら、コモンペットを売却または入れ替え、スペースあたりの生産効率を最大化しましょう。

## コードと無料報酬システム

開発者は、プレイヤーのスタートダッシュを支援するためにプロモーションコードを頻繁に配布しています。これらのコードを入力すると、無料のゲーム内通貨、スターターペット、序盤の進行を早める一時的な幸運ブーストなどを獲得できます。公式のリリース発表やメンテナンス情報については、[Game RantのRobloxガイド](https://gamerant.com/hide-ur-base-steal-codes-roblox/)などの検証済みメディアをチェックするのもおすすめです。

### ゲーム内コードの引き換え手順

コードの引き換えは簡単ですが、入力画面がUIの少し奥まった場所にあります：

1. 公式Robloxクライアントからゲームを起動します。
2. キャラクターが地上マップに完全にロードされるまで待ちます。
3. 画面の端（HUD）にある**ショップ（Shop）**アイコンをクリックまたはタップします。
4. ショップウィンドウを一番下までスクロールすると、コード入力ボックスが表示されます。
5. 有効なコードを正確に入力（または貼り付け）します。余分な空白が入らないよう注意してください。
6. **Redeem（引き換え）**を押すと、報酬が即座に所持金やインベントリに反映されます。

```
ショップアイコン ➔ 最下部までスクロール ➔ 有効なコードを入力 ➔ Redeemを押す
```

*（注：開発者コードは事前予告なしに有効期限が切れることがあります。新しいマイルストーン達成時の最新コードを見逃さないよう、Roblox内のSutik x Tommyなどのコミュニティグループをチェックしておきましょう）。*

## よくある質問（FAQ）

### hide ur base and steal how to playで最も重要なルールは何ですか？
一番の鉄則は「隠蔽」です。他のプレイヤーの視界に入る場所に入り口マーカーを置いてはいけません。また、ライバルの偵察者に尾行されている最中に自分のポータルへまっすぐ走るのも絶対に避けましょう。

### 基地に入られた場合、ペットをすべて盗まれてしまいますか？
侵入者は基地内のペットを盗むことができます。だからこそ、配置場所の秘匿と警戒を怠らないことが不可欠です。防御設備を強化し、収益をこまめに保管しておくことで、不意の襲撃による被害を最小限に抑えられます。

### ゲームの有効なプロモーションコードはどこで見つかりますか？
コードは開発者の公式SNS、Sutik x TommyのRobloxコミュニティグループ、主要なゲーム攻略サイトで公開されています。引き換えはゲーム内ショップメニューの最下部から行えます。

### 主力ペットを盗まれてしまった場合、どうやって立て直せばいいですか？
最強のペットを盗まれても、サーバーから退出する必要はありません。残った資金で安価なペットを買い直すか、ライバルの拠点を突き止めて代わりのペットを奪い返し、素早く収益ルートを再構築しましょう。
