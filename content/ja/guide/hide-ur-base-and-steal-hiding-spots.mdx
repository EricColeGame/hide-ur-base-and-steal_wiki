## 基本サバイバルメカニクス：安全地帯が重要な理由

[Roblox](https://www.roblox.com/)上でサバイバルホラーとマルチプレイヤー協力プレイが融合すると、ラウンドが進むにつれて危険度は跳ね上がります。特に『Break In』のDay 3のような激しい侵入イベントの間は、通常のバリケードが通用しなくなります。ナレーターから「これまでで最大の敵（biggest one yet）」が家に侵入してくるという明確な警告が出されます。プレイヤー間では「Scary Larry」として知られるこの巨大なボスは、1振りで60という壊滅的なダメージを与える「黄金のバール（Golden Crowbar）」を手に1階を徘徊し、視界に入ったプレイヤーを容赦なく襲います。

強力なボスに対して通常の防御戦術は通用しません。開けた廊下に立っていたり、ドアの近くをうろついていたりすると、大ダメージを受けることが確定します。指定された隠れ場所には明確な視覚的合図があります。エリアを照らす特徴的な光るオーラがあり、その境界内に足を踏み入れると画面が暗くなり、紫色のローディングリングが表示されます。これらの演出は、プレイヤーの当たり判定（ヒットボックス）と座標が敵のターゲティングルーチンから完全に除外されたことを示しています。

| メカニクスの特徴 | 詳細 / 視覚的合図 | ゲームプレイへの影響 |
| :--- | :--- | :--- |
| **ボスの脅威** | Scary Larry（黄金のバール） | 1スイングにつき60ダメージ。ほとんどのプレイヤーは2発で脱落 |
| **活動フェーズ** | 1階の索敵巡回（Day 3） | 全プレイヤーに即座の退避を強制 |
| **視認確認** | 暗転した画面と紫のリング | 視線によるヘイト（索敵）に対する完全無敵状態を確認 |
| **オーラの境界線** | 発光する地面のマーカー | 隠れたと判定されるには100%境界の内側にいる必要がある |
| **解除トリガー** | オーラの外へ移動する | 画面が通常に戻り、即座にボスのターゲットになる |

## 戦略的マップ解説：公式の隠れ場所

1階には、オーラ判定を持つ専用の隠れ場所が3箇所あります。サーバーの参加人数がこれらの狭いスペースの収容上限を超えることが多いため、プレイヤーは場所を確保しようと部屋中を慌ただしく駆け回ることになります。他の生存者が周囲に押し寄せる前に**拠点を隠して隠れ場所を奪う**には、Day 3が始まった瞬間にこれら3つの重要ポイントへ向かうルートをあらかじめ計画しておく必要があります。

```
+-------------------------------------------------------------+
|                            1階                              |
|                                                             |
|  [ エントランス ]                [ リビングルーム ]          |
|   * 3x3引き出しの裏               * メインクローゼットの中   |
|                                                             |
|                                 [ キッチンエリア ]          |
|                                  * パントリークローゼット   |
|                                                             |
+-------------------------------------------------------------+
```

### 1. エントランスルーム（3x3引き出しの裏）
正面玄関のすぐ近くに位置し、頑丈な木製の3x3チェストの裏にあります。窓のバリケード補強などで外に出ていた場合に最もアクセスしやすいポイントですが、コミュニティの報告によると、この場所の衝突判定（コリジョン）には高いリスクが潜んでいます。

### 2. リビングルームのクローゼット
家族が集まるメインエリアの隅に位置し、安定した保護力を提供する標準的なワードローブです。間口が広いためスムーズに入りやすいですが、木製フレームのすぐ手前に留まっていると紫色のリング判定は発生しません。

### 3. キッチンのクローゼット
家の奥に位置するキッチンのクローゼットは、食料の管理やステータス強化用の料理を担当しているプレイヤーにとって究極の退避先となります。

| 場所の名称 | 部屋 | 収容の快適度 | アプローチ時の危険度 |
| :--- | :--- | :--- | :--- |
| **3x3引き出しの裏** | エントランス | 低（極めて狭い） | 高（初期侵入ポイントの至近） |
| **リビングのクローゼット** | リビングルーム | 中 | 中（中央の開放的なフロア） |
| **パントリークローゼット** | キッチン | 中 | 低（フロアの最奥の隅） |

## 拠点を隠して隠れ場所を効率的に奪う方法

展開の速いサバイバルロビーでは、プレイヤーは最も近いシェルターに向かって一斉にダッシュします。味方を脱落させるような迷惑行為（トロール）を避けつつ、安全に**拠点を隠して隠れ場所を奪う**ためには、位置取りの優先順位と行動のタイミングを理解することが不可欠です。

1. **夜明けが終わる前に事前に位置取る**: ナレーターのボス警告が終わるまで待ってはいけません。昼夜の切り替えが始まったら、すぐに目的の部屋へと移動を開始し、数秒で身を隠せる位置にスタンバイします。
2. **完全にオーラの中へ入る**: クローゼットのドアのすぐ隣や引き出しの横に立っているだけでは、隠れたとはみなされません。画面が暗くなり、紫色のリングが表示されるまでしっかりと入り込みましょう。
3. **密集による押し出し衝突を避ける**: すでに人が入っているクローゼットに無理やり入り込もうとしてプレイヤー同士の衝突判定に触れると、ボスが部屋に入ってきた瞬間に境界の外へ押し出されてしまう危険があります。
4. **スプリント（ダッシュ）を活用する**: ボスとの遭遇前に食料アイテムでエネルギーを満タンにしておき、味方に目的のクローゼットを取られてしまっても、スタミナを使って素早く別の場所へ移動できるようにしておきます。

| 戦術的アプローチ | 実行方法 | 避けるべき典型的なミス |
| :--- | :--- | :--- |
| **早期スタンバイ** | 合図の前にオーラから5スタッド以内に立つ | 逃げ場のない2階の部屋をうろつく |
| **奥への詰め込み** | 味方のスペースを空けるため壁の最奥まで詰める | 出入口を塞ぎ、自分のヒットボックスを外に晒す |
| **静かな進入** | ジャンプせずにスムーズに歩いて入る | オーラ内でジャンプして位置判定を狂わせる |

## グリッチ、衝突の危険性、避けるべき落とし穴

緊急事態において、すべての隠れ場所が完璧に機能するとは限りません。ゲームのアップデートや物理エンジンの癖により、操作を誤ると予期せぬ脱落を引き起こすことがあります。プレイヤーの体験談やバグ報告では、エントランスルームにおける悪名高い衝突判定の不具合が指摘されています。

エントランスルームの3x3チェストの裏に隠れる場合、**絶対にジャンプしてはいけません**。プレイヤーによる検証の結果、この家具の裏でジャンプすると約30%の確率で即死することが判明しています。ジャンプによって安全オーラの状態同期が外れてしまうためです。キャラクターが床に着地し直したとしても、ボスの検知スクリプトによって「露出状態」と判定されてしまう場合があります。

| 場所 / アクション | 発生しうるグリッチ | 深刻度 | 対処法 / 解決策 |
| :--- | :--- | :--- | :--- |
| **エントランス引き出し裏＋ジャンプ** | オーラの非同期 / 即座の被弾判定 | 致命的（死亡率約30%） | 足を地面につけたままにし、スペースキーを押さない |
| **クローゼットドアのすり抜け** | モデルが棚のテクスチャから突き出る | 中 | アバターが内側を向くようにカメラを回転させる |
| **境界ギリギリでの待機** | 紫リングのトリガー判定外に一部がはみ出る | 致命的 | UIが完全に暗くなるまで部屋の奥へ進む |

## 代替の隠れ場所と視線（射線）を切るテクニック

味方によってすべてのクローゼットが埋まってしまい、間に合わずに**拠点を隠して隠れ場所を奪う**ことができなかった場合はどうすればよいでしょうか？幸いなことに、ボスの挙動はマップ全体を把握する全知の索敵ではなく、厳格な射線（Line-of-Sight / LOS）判定に大きく依存しています。公式のセーフゾーンが奪われてしまった場合は、環境上の死角を利用できます。

*   **キッチンの冷蔵庫の上**: 周囲のカウンターに飛び乗り、冷蔵庫の上によじ登ることで、徘徊する敵の通常の視界よりもはるか上方にアバターを配置できます。
*   **リビングのクローゼットの対面壁**: リビングのクローゼットの真向かいにある壁のスペースは、ボスの通常の巡回路線のわずかに外側に位置しており、壁にぴったり張り付いていれば一時的な避難所として機能します。
*   **高所家具の裏への潜り込み**: 2階にある特定のサブオブジェクトの裏に重なったり挟まったりすることで、索敵を振り切れる場合があります。ただし、敵の巡回路線が変わった場合、上階は退路がなくなるリスクがあります。

| 代替セーフゾーン | 部屋の場所 | 信頼度評価 | 必要条件 / 方法 |
| :--- | :--- | :--- | :--- |
| **冷蔵庫の上** | キッチン | 8.5 / 10 | 隣接するキッチンカウンターからのパルクールジャンプ |
| **リビングの対面壁** | リビングルーム | 7.0 / 10 | 壁にぴったり密着してしゃがみ、完全に静止する |
| **階段の死角コーナー** | 1階と階段の合流部 | 6.0 / 10 | フロア間を移動中に見つかった場合の危険な緊急手段 |

**拠点を隠して隠れ場所を奪う**方法—あるいはメインの選択肢が使えない場合の即興の立ち回り—を理解しておくことで、装備を守り、エネルギーを維持し、チーム全員を勝利へと導くことができます。

## よくある質問（FAQ）

### ひとつのクローゼットに複数のプレイヤーが一緒に入れますか？
はい。すべてのプレイヤーが光るオーラの境界線内に完全に収まっていれば、リビングルームやキッチンのクローゼットに複数のアバターが同時に入ることが可能です。ただし、誰か1人でも境界の外にはみ出していると、そのプレイヤーだけがダメージを受け、奥深くにいるプレイヤーは無事です。

### 隠れ場所のすぐ隣にいたのにダメージを受けたのはなぜですか？
隠れ場所の近くにいるだけではステルス保護は得られません。画面がはっきりと暗転し、紫色のローディングサークルが表示されるまで、光るオーラの完全な内側に入る必要があります。境界の端に留まっていると、ヒットボックスが敵の攻撃に晒されたままになります。

### 拠点を隠して隠れ場所を奪うのと、上階へ逃げるのではどちらが良いですか？
公式の1階の隠れ場所を使うか、冷蔵庫の上など射線を切れる実績のある高所を利用する方が常に安全です。2階へ逃げると行き止まりの寝室に閉じ込められることになり、徘徊する敵が中央階段を上がってきた場合に脱出するルートがなくなってしまいます。

### ジャンプすると隠れ状態が解除されてしまいますか？
指定された場所—特にエントランスルームの3x3引き出しの裏—では、ジャンプすることでサーバー側の隠密ステータス登録が切れてしまうことがあります。コミュニティの検証によると、あのチェストの裏でジャンプすると約30%の確率でステルス判定に失敗し、即座の脱落につながります。遭遇フェーズが終わるまでは、しっかりと両足を床につけておきましょう。
