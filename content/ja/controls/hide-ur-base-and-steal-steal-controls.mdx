## アクション別の実践テクニック：強盗の解剖学

強盗を成功させるプロセスは、「索敵」「潜入」「脱出」の3段階に分かれます。各フェーズでどのキーを押すべきかを身体に叩き込んでおくことが、資産を守る鍵となります。

```
[フェーズ1: 索敵] -> 周囲をスキャン、カメラズームを調整
       │
[フェーズ2: 潜入] -> マーカーに接近、インタラクト（E / タップ / X）を押す
       │
[フェーズ3: 奪取と逃走] -> 強盗プロンプトを長押し、180度反転、ポータルから脱出
```

### 1. 隠された拠点ポータルの見つけ方

多くのプレイヤーは、崖の下、茂みの奥、または建築物の上などにポータルを隠す傾向があります。
- カメラは常にできる限り引いた（ズームアウト）状態に保ちましょう。
- PCではシフトロック機能を活用し、カメラの向きを変えずに壁際を横歩き（ストレイフ）で確認します。
- 拠点の持ち主に気付かれないよう、開けた視界の通る場所を走るのは避けましょう。

### 2. ペット奪取のメカニクス

敵のマーカーを踏むと、一瞬で相手の拠点内部へとテレポートします。価値の高いペットを素早く見極めることが肝心です。ターゲットのペットに近づくと、インタラクトプロンプトが表示されます。

ゲージが完全に溜まるまで、インタラクトキーを長押しし続ける必要があります。もし盗んでいる最中に拠点の持ち主が戻ってきた場合は、キーを離して即座にジャンプし、反撃を回避してください。**hide ur base and steal steal controls** を完全にマッスルメモリー（筋肉の記憶）に定着させておくことで、逃走直前にペットを取り落とすようなミスをゼロにできます。

| 潜入フェーズ | 最適な入力戦略 | 危険度 |
| :--- | :--- | :--- |
| **拠点進入時** | テレポート直後に素早くしゃがみ・横移動 | 低 |
| **金庫室の索敵** | 前進せずフリールックカメラで全体を見渡す | 中 |
| **ペット奪取中** | インタラクト長押し、親指はジャンプに待機 | 高 |
| **脱出ダッシュ** | 振り向かずに脱出ポータルへ一直線に直行 | 極めて高い（危険） |

## 高度な移動テクニックと拠点の最適化

基本的なキー配置を覚えるだけでは不十分です。上級プレイヤーは、移動テクニックを使ってサーバーのレイテンシ（遅延）を突き、防衛側を巧みに翻弄します。

### シフトロックを活用したコーナーピーク（覗き込み）

PCで左Shiftキーを押す（またはモバイルで手動カメラフォーカスを設定する）と、キャラクターの向きがクロスヘアに追従します。これにより、胴体の当たり判定を晒すことなくシェルターの壁沿いを滑るように移動し、拠点オーナーがペットを見張っているかどうかを安全に確認できます。

### ジャンプ強盗キャンセル（Jump-Steal Cancel）

ペットのケージを操作する際、盗み出しバーが満タンになる直前にジャンプ入力を先行入力（バッファリング）しておく技です。成功すると、ペットが手に入った瞬間にキャラクターが脱出ポータルへ向かって空中に飛び出すため、防衛側のプレイヤーが反撃を当てるのは極めて困難になります。

### ポータル擬態・設置場所の選定

拠点を設置するキーを「いつ」「どこで」押すかが、長期的な生存率を決定づけます。コミュニティで評価されている主な設置場所の安全性は以下のとおりです。

| 拠点設置場所 | 視認性の低さ | 脱出難易度 | 総合的な実用性 |
| :--- | :--- | :--- | :--- |
| **高い崖の縁** | 非常に低い（見つかりにくい） | 高 | 優秀 |
| **密集した低木の中** | 低い | 低 | 普通 |
| **リスポーン地点の目の前** | 極めて高い（丸見え） | 低 | 最悪 |
| **マップ境界の角** | 低い | 中 | 高い |
| **水没した水場の中** | 非常に低い（見つかりにくい） | 高 | 最高ランク |

## 操作に関するトラブルシューティング

入力の無反応によってレアなペットを奪われることほど悔しいものはありません。ここでは、コミュニティから報告されている代表的な操作の不具合と、その実践的な対処法を紹介します。

1. **インタラクトプロンプトが表示されない：**  
   拠点マーカーの上に立っているのにプロンプトが出ない場合、通信ラグによりキャラクターの位置判定がズレている可能性があります。2歩ほど後ろに下がり、カメラの遮蔽物をなくしてから、歩いて近づき直してください。
2. **モバイルの仮想スティックが戻らない（入力が残る）：**  
   指を離してもキャラクターが勝手に動き続ける場合は、Robloxのアプリ内設定を開き、移動モード（Movement Mode）を「ダイナミックサムスティック」から「クラシックサムスティック」に変更してください。
3. **シフトロックが機能しない：**  
   ゲーム内設定メニューで「Shift Lock Switch（シフトロックスイッチ）」の項目が「オン（Enabled）」になっているか確認してください。ここがオフになっていると、左Shiftを押してもカメラは固定されません。
4. **コントローラー使用時のインタラクト遅延：**  
   PCやモバイルでワイヤレスゲームパッドを使用している場合は、Bluetoothの電波干渉を確認してください。わずか50ミリ秒（ms）の入力遅延でも、強盗の成否を分ける致命傷になります。

## よくある質問（FAQ）

### PC版のデフォルトの hide ur base and steal steal controls は何ですか？
PCの標準操作は、W/A/S/Dキーでキャラクター移動、スペースキーでジャンプ、左Shiftキーでシフトロック（カメラ追従）、Eキー（または左クリック）でペットの強盗やポータルへのインタラクトを行います。

### 他のプレイヤーが警備している状態でペットを盗むにはどうすればいいですか？
防衛プレイヤーが視線をそらす瞬間を待ち、ダッシュで接近してインタラクトキーを長押しします。相手が迫ってきた場合は、即座にジャンプで盗みをキャンセルして離脱し、カメラ位置を立て直して次のチャンスを伺いましょう。

### ゲーム内で操作のキー割り当てをカスタマイズできますか？
移動やジャンプなどの標準的な操作はRobloxクライアント全体の設定を引き継ぎますが、ショップメニューやインベントリ切り替えといったゲーム固有のUI要素は、各プラットフォームごとに固定のレイアウトとなっています。

### アクションキーを押しても拠点マーカーが設置できないのはなぜですか？
拠点のポータルは、指定のセーフゾーン外かつ他のプレイヤーが専有していない、障害物のない平らな地面にのみ設置できます。キーを押しても反応しない場合は、開けた障害物のない地形へ移動して再度お試しください。
