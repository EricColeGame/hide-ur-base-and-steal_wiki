### 戦略的な設置ステップ

1. **離れた地形を探索する:** 中央広場付近には絶対に設置しないでください。複雑な岩場、生い茂る茂み、影の濃い地形の端などを目指しましょう。
2. **カメラを真下に向ける:** マウスや右スティックを使って視点を真下に向けます。これにより、地形との重なり具合を最も正確に視認できます。
3. **設置キーを入力する:** 隠蔽入力を行い、ハッチのマーカーを暗いテクスチャに重ねるか、茂みの下に沈むように配置します。
4. **インタラクト可能距離をテストする:** 一歩離れてから再度近づいてみてください。不自然にジャンプすることなく、スムーズにインタラクト表示が出るか確認します。

プレイヤーの検証や[GameRantのRoblox特集記事](https://gamerant.com/hide-ur-base-steal-codes-roblox/)でも触れられているように、拠点の収益は受動的にお金を生み出す高Tierのペットを維持できるかに大きく依存しています。侵入者に気づかずペットを奪われてしまうと、何時間分もの積み上げた利益が一瞬で水の泡になります。

### 戦術比較：潜入（攻撃） vs 拠点防衛（守備）

| 特徴 | 侵入・レイド（攻撃側） | 拠点防衛（防衛側） |
| :--- | :--- | :--- |
| **主な焦点** | 微小なテクスチャや床のわずかなマークを発見 | 入り口を完璧に隠し、侵入音を警戒する |
| **重要操作** | ダッシュ、連続ジャンプ、即時インタラクト | 素早いカメラ操作、防衛トラップの発動 |

| **リスク度** | 低（手ぶらで捕まっても時間を失うだけ） | 極めて高（高収益ペットを失うリスク） |

## 入力遅延とポータル設置ミスのトラブルシューティング

*Hide ur Base and Steal*では、フロアマーカーを登録する際にクライアントとサーバー間の正確な座標判定を行っているため、隠蔽アクションが発動しなかったり、意図しない場所にポータルが落ちてしまう不具合が発生することがあります。

| よくある問題 | 主な原因 | 解決策 |
| :--- | :--- | :--- |
| **インタラクト表示が出ない** | 複雑・凸凹な地形の近すぎる位置に立っている | 2歩後ろに下がり、カメラ角度を変えて再度近づく |
| **拠点が設置できない** | 他のプレイヤーの保護エリアと重複している | 既存の建造物から少なくとも20スタッド以上離れる |
| **「E」キーの入力遅延** | Ping値が高い、またはRobloxサーバーが不安定 | インタラクトキーを再設定するか、低Pingサーバーに移る |
| **地形の隙間に挟まる** | 判定が反転したコリジョンの下にハッチを置いた | Robloxメニューの「キャラクターをリセット」を使うか、出口ポータルを触る |

スピードが命となる過密サーバーに挑む前に、人の少ない静かなサーバーで**hide ur base and steal hide controls**の操作感を練習し、正確な有効距離を身体に覚え込ませておきましょう。

## 上級者向け：移動とカモフラージュの極意

コミュニティの上級プレイヤーたちが実践している、自分は素早く出入りできる状態を保ちながら、他者からは拠点を目視不可能にする高度なテクニックをいくつか紹介します。

### 1. シャドウ・アライン法（影合わせ）
木や巨大な岩などのオブジェクトが落とすリアルタイムの影は、地面に暗い影を作ります。この影のプールの中にベースマーカーを正確に重ねると、ポータルマーカーの外枠が周囲の明るさと同化し、真下を凝視して探さない限り通りすがりのプレイヤーにはほぼ見えなくなります。

### 2. エッジ・クリッピング（当たり判定の隙間埋め）
一部の建造物には、見た目のモデルと実際の当たり判定（コリジョン）の間にわずかな隙間が存在します。アナログスティックやWASDを細かくタップしてキャラクターをその隙間に潜り込ませることで、オブジェクトの下にポータルを半分埋め込むことができます。自分はインタラクトできる状態のまま、外部からの視界を完全に遮ることができます。

### 3. 出口ポータルのダッシュキャンセル
拠点からオーバーワールドへと戻る瞬間は、無防備な隙が生じます。テレポートのロード画面中に**Shift**（ダッシュ）キーを先行入力（バッファリング）しておくことで、地上に出た瞬間にトップスピードで走り出すことができ、出口で待ち伏せしているキャンパーのエイムや追撃を回避できます。

## よくある質問（FAQ）

### PC版のHide ur Base and Stealの基本操作は何ですか？
PCで隠し入り口を設置・収納・入場するためのメインキーは、アクションバーで拠点ツールを持った状態での**Eキー**（インタラクト）または**左マウスクリック**です。基本移動は**W、A、S、D**、ジャンプは**スペースキー**、ダッシュは**左Shift**に割り当てられています。

### マップの特定の場所で拠点が設置できないのはなぜですか？
中央ハブの周辺、ショップエリア、他のプレイヤーのリスポーン地点付近などは、システム上で保護エリア（セーフゾーン）に設定されています。これらの保護エリア内で**hide ur base and steal hide controls**を使おうとしても、設置マーカーが赤色になって登録されません。少し離れた岩場やフィールドの外縁部に移動して設置してください。

### 隠したベースマーカーは他のプレイヤーからも見えますか？
はい、完全に透明になるわけではありません。地面に控えめなフロアデカールや落とし戸として表示されます。そのため、自然の障害物や影、地形の角などをうまく利用して視線を遮り、インタラクト表示に気づかれずに素通りさせる工夫が必要となります。

### 敵の拠点に侵入した後、どうやってペットを盗むのですか？
**hide ur base and steal hide controls**を駆使して敵のポータルに侵入できたら、保管庫内に置かれているペットに近づきます。メインのインタラクトボタン（PCは**E**、スマホはタップ、コンソールは**X/□**）を押してターゲットのペットを拾い、急いで出口ポータルに戻って自分の拠点へ持ち帰ることで略奪完了となります。
