## ゲーム概要：基本メカニクスとゲームサイクル

『Hide ur Base and Steal』の核となるコンセプトは、古典的なタイクーンの成長要素と、緊迫したかくれんぼの駆け引きを融合させたものです。区画があらかじめ固定されている標準的な拠点建築ゲームとは異なり、本作では持ち運び可能なグラウンドマーカーが与えられます。

このマーカーを地面に設置すると、自分だけの地下シェルターへと直接つながる専用ポータルとして機能します。シェルター内では、時間経過とともに継続的にお金を生み出してくれるペットを購入・合成・配置していきます。

しかし、地上には常に危険が潜んでいます。サーバー内の他のプレイヤー全員が、あなたとまったく同じ目的を持っているからです。もし対戦相手にあなたのマーカーを見つけられてしまうと、彼らはポータルをくぐってシェルターへ侵入し、最も価値の高いペットを根こそぎ奪い去っていく可能性があります。

ゲームプレイが各フェーズでどのように展開するかを把握するために、以下の全体概要を確認しておきましょう：

| フェーズ | 主な目的 | 主なリスク | 最優先戦略 |
| :--- | :--- | :--- | :--- |
| **フェーズ1：配置** | 入り口マーカーを秘密の場所に置く | 設置中に目撃されること | 射線が通らない場所の選定、植物によるカモフラージュ |
| **フェーズ2：拠点経済** | 収益を生むペットの孵化とレベル上げ | 資金が枯渇すること | 初期の利益を移動速度や孵化速度へ再投資 |
| **フェーズ3：索敵** | 敵のマーカーを探してマップを偵察 | 待ち伏せされる / 自分の拠点を失う | 高所からの観察、人里離れたマップ境界の探索 |
| **フェーズ4：潜入** | 隠された拠点へ侵入して資産を強奪 | 略奪中に戻ってきた拠点所有者に見つかる | 素早い略奪ルートの確保、高レアリティペットの優先確保 |

防御と攻撃のバランスを取ることが極めて重要です。隠れることに時間を使いすぎて一度もレイドを行わなければ、経済的な成長は停滞します。逆に、自分の入り口の安全を確保せずに狩りばかりに夢中になっていると、留守の間にペットインベントリを空っぽにされてしまうでしょう。

## 入り口マーカーを完璧に隠す方法

このゲームの鉄則は非常にシンプルです。「開けた場所にマーカーを置いてはならない」ということ。経験豊富な襲撃者たちは、広い草原、中央の広場、目立つ交差点を絶えず警戒しています。

ライバルにシェルターを荒らされないようにするには、地形のテクスチャにシームレスに溶け込む場所、高低差のある立体的な地形、あるいは死角になるポイントを選ぶ必要があります。プレイヤーの経験則として、ベテラン建築者たちは自然の茂みの密集地、突き出た岩の下、狭い岩の裂け目などを好んで利用します。

### カモフラージュスポットおすすめランキング

| 場所のタイプ | ステルス評価 | 人通り | 推奨事項 / 特徴 |
| :--- | :--- | :--- | :--- |
| **密集した木立・茂みの中** | 9/10 | 低 | 低木の当たり判定内に直接マーカーを設置。通りがかりのプレイヤーにはほぼ視認不可能。 |
| **崖の裂け目・岩棚** | 8.5/10 | 極めて低 | 到達にパルクールが必要。崖下の岩棚までわざわざ確認しに来る横着なプレイヤーは稀。 |
| **建築オブジェクトの裏** | 7/10 | 中 | 一見しただけでは見つかりにくいが、建物を探索し尽くすプレイヤーには見つかるリスクあり。 |
| **マップの外周境界** | 8/10 | 低 | 移動に時間がかかるため人通りが少ない。長時間のAFK（放置）稼ぎに最適。 |
| **開けた空き地** | 1/10 | 最大 | 非常に危険。設置から数分以内に襲撃される可能性が極めて高い。 |

### 防御的配置の3原則

1. **設置前に周囲360度を確認する：** 拠点を設置するボタンを押す前に、必ずカメラを回転させて周囲を見回してください。もし背後を尾行されていた場合、ポータルの位置が即座にバレてしまいます。
2. **明暗のコントラストが強い場所を避ける：** 自然な影が落ちる場所にマーカーを設置しましょう。Robloxの動的ライティングの仕様上、日当たりの良い芝生の上では鮮やかなマーカーが悪目立ちしてしまいます。
3. **脱出ルートを想定しておく：** 拠点から出る際、安全に逃げられるルートがあるか確認してください。出た瞬間に待ち伏せに遭うような配置は避けるべきです。

## 索敵と強奪：潜入のプレーブック

拠点を安全に隠し終えたら、次は攻撃フェーズの始まりです。敵のシェルターを効率的に探し出して略奪するノウハウこそが、カジュアルプレイヤーと一流のタイクーンを分ける決定的な要素となります。

サーバー内を縦横無尽に駆け巡り、拠点を隠しつつ敵の隠しポータルを奪うプレイスタイルをマスターすれば、経済の成長スピードは飛躍的に跳ね上がります。何千コインも費やしてノーマルペットを孵化させる代わりに、他のプレイヤーが無防備に残していった激レアペットへ忍び寄り、手に入れることができるからです。

### 潜入チェックリスト

| ステップ | 目的 | 戦術的アドバイス |
| :--- | :--- | :--- |
| **1. 高所からの索敵** | 地面にあるマーカーを目視で探す | 塔、崖、木の上に登り、周囲の地形と色が異なる不自然なテクスチャを探す。 |
| **2. 標的の動向確認** | 拠点の所有者がアクティブか確認 | プレイヤーリストを確認し、ターゲットがマップの反対側で作業中であれば、安全な潜入チャンス。 |
| **3. 潜入ダッシュ** | 誰にも気づかれずにポータルへ突入 | 他のプレイヤーに尾行されないよう、障害物や地形の遮蔽物を利用して背後から接近する。 |
| **4. 高価値資産の持ち出し** | 最高ティアのペットを最優先で回収 | 素早くステータスを確認し、見た目の派手さよりも高い倍率（マルチプライヤー）を持つペットを優先。 |
| **5. 確実な脱出** | 脱出して安全な場所へ持ち帰る | 奪った富を確実に保護するため、寄り道せず自分のシェルターへ直行して保管する。 |

コミュニティの報告でも、タイミングの重要性が強調されています。もし中央のショップと拠点を頻繁に行き来しているプレイヤーを見かけたら、そのプレイヤーが買い物を始めるまで待ってからマーカーに飛び込みましょう。そうすることで、相手のシェルター内で邪魔されることなく略奪できる時間を最大限に確保できます。

## 経済成長：ペット倍率の最大化

ペットは、このゲームにおける成長の要となるメインエンジンです。略奪したペットや孵化させたペットは一定間隔でお金を生み出し、シェルターの金庫を満たしていきます。

ペットのスロットを効率化しないと、キャッシュの獲得ペースはすぐに頭打ちになります。序盤はインベントリ容量と移動速度のアップグレードを最優先に進めましょう。移動速度が上がれば、標的を探してマップ全体を素早く探索できるようになります。

### ペットのティア進行度一覧

| ティア | 入手方法 | 一般的な基本倍率 | リスクレベル |
| :--- | :--- | :--- | :--- |
| **Common / Basic（コモン）** | 初期のエッグ孵化 | 1.0倍 – 1.5倍 | 低（盗難の標的にされにくい） |
| **Rare（レア）** | 上級エッグ / レイド略奪 | 2.0倍 – 3.5倍 | 中 |
| **Epic（エピック）** | 高級エッグ / 幸運なレイド | 5.0倍 – 8.0倍 | 高（侵入者に狙われやすい） |

致命的な損失を防ぐため、入り口マーカーが完璧に隠蔽されていない限り、高ティアのペットを並べたままシェルターから遠く離れないようにしましょう。拠点を隠し敵の拠点を奪うゲームサイクルに慣れてくれば、低ティアのペットをライバルから奪った高倍率のトロフィーペットへと順次入れ替えていくことができます。

## 上級サバイバル術＆サーバーホッピング戦略

どのサーバーに身を置くかは、勝率に大きな影響を与えます。高レベルのアグレッシブなプレイヤーがひしめく満員サーバーでは、設置したマーカーが高頻度で見つかってしまいます。シェルターが絶え間なく襲撃されてしまう場合は、サーバーホッピング（サーバー変更）を検討しましょう。

3〜5人程度しかいない過疎サーバーは、ソロでの安全なファーム（金策）に最適です。しっかりと拠点を隠して経済基盤を整えつつ、数少ない対戦相手の拠点をじっくりと探索できます。

さらに、「拠点を固定しない動的な移動」も勝利のための強力なプレイスタイルです。一度設置したポータルを、プレイセッション中ずっと同じ茂みに放置してはいけません。近くのプレイヤーを略奪したら、即座に別のエリアへマーカーを移しましょう。手慣れたプレイヤーは復讐のために足取りを追跡してきます。常に移動し続けることで、報復レイドを未然に防ぐことが可能です。拠点をどこに隠し、どこから奪うかを柔軟に変え続けることで、ライバルに対して常に予測不能な優位性を保つことができます。

## よくある質問（FAQ）

### 自分がシェルター内にいる時に他のプレイヤーがマーカーを見つけたらどうなりますか？
中にいる最中に敵がポータルマーカーを踏んだ場合、敵はそのままあなたのシェルター内へ入ってペットを奪おうとしてきます。常に周囲を警戒し、入り口が見える位置や高価値ペットの近くに陣取って、即座に迎撃や防衛行動が取れるようにしておきましょう。

### 一度設置したマーカーを別の場所に移動させることはできますか？
はい、ポータルマーカーはいつでも回収して再設置できます。近隣のプレイヤーを略奪した直後や、拠点の周辺をうろつく不審な偵察者を見かけた際は、定期的に場所を変えることを強くおすすめします。

### マップ上に隠された敵の拠点を見つけるコツはありますか？
高所からの索敵を徹底してください。木、高塔、崖の上など高いオブジェクトに登り、可能であればグラフィック設定でフォグ（霧）を下げて視界を広げましょう。草むらからわずかに突き出たマーカーの発光エフェクトや、不自然なオブジェクトの配置など、地形の細かな違和感を探すのがコツです。

### なぜこのゲームでは拠点を隠して敵の拠点を奪うことがそれほど重要なのですか？
このゲームの経済システムはすべてペットの収集を中心に回っているためです。拠点が簡単に見つかる場所にあれば、苦労して手に入れた資産は他のプレイヤーに絶え間なく奪われてしまいます。逆に、ライバルの隠れ家を見つけ出して略奪することこそが、ゲーム内で最も素早く資金を稼ぎ出す手段となるからです。
