## 基本システムの理解：タイクーンの潜伏と略奪

Sutik x Tommyが[Roblox公式プラットフォーム](https://www.roblox.com/)上で開発した『Hide ur Base and Steal』は、クラシックなタイクーンの成長要素と、スリリングな隠れんぼ（ステルス）要素が融合したゲームです。巨大で派手なネオン区画の上に堂々と施設を構える従来の拠点構築ゲームとは異なり、本作ではオープンワールド上の地面に小さな「入口マーカー」を設置する必要があります。

自身が隠したマーカーを踏むと、キャラクターは地下や別次元の隠れ家へと直接テレポートします。この安全地帯の中でペットを購入し、収入倍率を強化し、不労所得となる現金を生成します。しかし、サーバー内の他のプレイヤー全員が「あなたのマーカーを見つけ出し、拠点に侵入して、気づかれる前に高価なペットを奪い取る」という共通の目的を持っています。

| システム | 仕組み | 戦略的重要性 |
| :--- | :--- | :--- |
| **入口マーカー** | 地表に設置する小さなノード | 敵に拠点をどれだけ見つかりにくくできるかを左右する |
| **ペット生成** | 内部に配置したペットが時間経過で現金を自動生成 | 侵略者の標的；ペットを失うと進行がストップする |
| **略奪タイム** | 侵入者が戦利品を拾い上げるわずかな数秒間 | この猶予時間中に侵入者の足を止める防衛レイアウトが必要 |
| **ショップ＆アップグレード** | 通貨で孵化速度、トラップ、ステータス強化を購入 | 長期的なサーバー支配と略奪被害からの経済的復旧を支える |

生き残るためには、攻撃的な潜入技術と防御的な隠蔽技術の双方を極めなければなりません。スポーンノードが露出していれば、内部にどれほどの富を蓄えていてもペットの安全は決して保証されません。

## 秘密のマーカー配置：絶対に見つからない入口の作り方

最初の防衛線は、完全に「地理的な要素」にかかっています。**安全な拠点**を作る際は、人目につく場所や一般的な移動ルートの近くに入口ポータルを絶対に置いてはなりません。ワールドマップには、視線を遮るように設計されたさまざまな高低差、影になるエリア、背景オブジェクトが存在します。

```
[メインハブ / スポーン地点] ──(超危険)──> 開けた平地
         │
         ├──(中危険)────> 目立つ壁の角
         │
         └──(最高安全地帯)─> 影の残骸 / 頭上のカモフラージュ / 高所の足場
```

コミュニティの報告によると、成功した略奪の80%以上が、メインマップのスポーン地点から50スタッド以内に配置された拠点に対して発生しています。侵入者は本能的に平坦で開けた地形を探すため、起伏の激しいマップの境界付近へ移動するだけで、初心者の略奪者を即座にふるい落とすことができます。

### 最適な設置場所 vs 最悪な設置場所

| 場所のタイプ | 危険度 | 発見率 | 成功または失敗の理由 |
| :--- | :--- | :--- | :--- |
| **ハブ周辺の開けた平地** | 壊滅的 | 3分以内に95% | 人通りが多いため、ほぼ瞬時に発見される。 |
| **茂みや小物の下** | 低 | 1セッションあたり約20% | 自然な影がマーカーの目立つ色合いを紛らわせる。 |
| **垂直な崖の足場** | 極めて低 | 1セッションあたり10%未満 | 到達するために意図的なアスレチックやパルクールが必要。 |
| **テクスチャ装飾やゴミの裏** | 最小限 | 1セッションあたり約5% | 特定の角度から覗き込まない限り、周辺視野から完全に隠れる。 |

### 戦術的配置のコツ
* **対称的なパターンを避ける：** 行き止まりの真ん中にマーカーを置かないでください。経験豊富な泥棒は真っ先に四隅をチェックします。
* **地表の色に同化させる：** 周囲の床テクスチャにより、マーカーパッドが自然と地面に溶け込む場所を選んで配置しましょう。
* **移動ルートを逆手に取る：** 飛び降りるとプレイヤーのカメラが下ではなく前方を向いてしまうような、段差の下の障害物の裏にマーカーを設置します。

## 拠点の内部要塞化：堅固なレイアウトの構築

侵入者がマーカーを踏んで中に入ってしまった場合、ペットを守る最後の砦となるのが内部のフロア設計です。整理されていないレイアウトでは、泥棒が一番稼げるペットへ一直線にダッシュし、それを奪って3秒以内に脱出できてしまいます。**安全な拠点**を構築するには、空間的な障害物を設ける必要があります。

| セキュリティ層 | 防衛セットアップ | 目的 |
| :--- | :--- | :--- |
| **第1層：エントランスホール** | 狭いチョークポイントや曲がりくねった通路 | 初期のダッシュの勢いを削ぐ |
| **第2層：ダミーポッド** | 手前に低ティアのおとりペットを配置 | 油断した侵入者を騙し、安価なアイテムを拾わせる |
| **第3層：最深部金庫** | 構造上の死角の先にある最も奥まった部屋 | 高ティアのペットを初期のカメラアングルから完全に隠す |
| **第4層：脱出トラップ** | 帰還ルート上にある狭いボトルネック | 防衛のためにテレポートで戻った際、泥棒を袋小路に追い詰める |

プレイヤーの経験則から、スポーンパッドとレアペットの保管スペースの間に距離を設けることで、極めて重要な対応時間が生まれることが分かっています。侵入者を知らせるサーバー通知が点滅した際、曲がりくねった通路を走る数秒の猶予があるだけで、略奪者を現行犯で捕まえられる確率が格段に上がります。

## 高価値ペットの保護と管理

ペットはキャッシュを生み出す主要なエンジンです。レアペットを失うと収入が激減し、稼いだ現金をアップグレードではなく、再び孵化システムへ再投資せざるを得なくなります。

```
ペット獲得 ──> 選別（低価格 vs レア） ──> 金庫へ保管 ──> 不労所得ループ
```

**安全な拠点**の中で安定した経済循環を維持するためには、ペットを資産価値ごとに階層化して管理してください。最高倍率を持つペットを、拠点入口のパッド付近にまとめて配置することは絶対に避けましょう。

| ペットのティア | 収入倍率 | 防衛戦略 | 配置の優先度 |
| :--- | :--- | :--- | :--- |
| **コモン / スターター** | 1倍 - 1.5倍 | 餌 / 陽動用 | 入口付近の外側の部屋 |
| **アンコモン / レア** | 2倍 - 4倍 | 第2の防壁 | 中層のサイド通路 |
| **エピック / レジェンダリー** | 5倍 - 10倍以上 | 隔離・厳重施錠 | 金庫の最深部の隅 |
| **イベント / 限定** | 変動（高倍率） | 常時監視 | メインの壁の裏にある隠し小部屋 |

### ペット保護のデイリーチェックリスト
1. **稼ぎ頭をローテーションする：** マップ探索のため拠点を離れる際、余剰利益を保管するか、誰かが周囲をうろついている疑いがあれば超レアペットを一時的に退避させましょう。
2. **ノードを分散させる：** ペットホルダーを部屋の様々な場所に散らして配置し、泥棒が一度の探索でコレクションを根こそぎ奪えないようにします。
3. **サーバーリストを監視する：** 攻撃的な略奪プレイヤーに注意を払ってください。手練れの泥棒がサーバーに参加してきたら、外のマーカー周辺の安全確認を行いましょう。

## アクティブな防衛と偵察の戦術

**安全な拠点**の防衛は、完全に受け身で行うものではありません。拠点が資金を生成している間も、ワールドマップ上の他プレイヤーの動きを能動的に追跡する必要があります。他プレイヤーがどこを捜索しているかを知ることで、自分の隠れ家が今危険に晒されているかどうかを判断できます。

| プレイスタイル姿勢 | 使用するタイミング | アクションプラン | 脅威への対応 |
| :--- | :--- | :--- | :--- |
| **タートル（防衛）** | 高価値ペットを配置した直後 | 内部の入口パッドが見える位置で待機 | 侵入した瞬間に敵を奇襲・迎撃 |
| **スカウト（哨戒）** | 新規セッションの序盤 | 外側の拠点の周囲を中距離で巡回 | 自分の足跡を追ってくるプレイヤーを特定 |
| **レイダー（攻撃）** | 資金が少なく、早急に資本が必要な時 | 反対側のエリアで敵のマーカーを探索 | 素早くペットを奪い、資金を確保 |

### 疑わしいプレイヤー行動の見分け方
「尾行者」には細心の注意を払ってください。一部のベテラン泥棒は、意図的にメインスポーン付近に留まり、無警戒なプレイヤーを遠くから尾行します。崖を越えたり建物を回ったりしても誰かがついてきていると感じたら、絶対にマーカーへ直行してはいけません。相手が興味を失うまでマップの何もない隅へと誘導し、隠れ家の場所を悟られないようにしましょう。

## 潜入ガイド：他人の拠点から安全に略奪する方法

バランスの取れた経済基盤を築くには、他人の拠点を略奪して自分の建設資金に充てることも必要です。**安全な拠点**で不労所得を得つつ、積極的な窃盗によりまとまった現金とペットを素早く調達しましょう。

```
外周の捜索 ──> 隠されたノードの特定 ──> 潜入 ──> 最上位ティアを狙う ──> 迅速な離脱
```

### 戦略的略奪のステップ
* **不自然な影を探す：** プレイヤーの設置パッドは、岩や凹凸のある地面に対してわずかな輪郭の違和感を生じさせます。ジャンプしながら地表を注意深くスキャンしましょう。
* **人通りの多い「死角」をチェック：** 初心者は滝の裏や大きな木の背後が完全に隠れていると思い込みがちです。これらは経験豊富な泥棒が真っ先に調べる場所です。
* **欲張らず脱出を最優先にする：** 敵の拠点に3体のペットがいた場合、最も価値の高い1体だけを奪って即座に脱出してください。安価なペットまで欲張って長居すると、所有者が戻ってきて捕まるリスクが跳ね上がります。

## コードと無料の進行ブースト

有効なプロモーションコードを引き換えることで経済の立ち上がりを早め、ペットの収穫だけに頼ることなく、拠点を強化するための資金を素早く手に入れることができます。

### コードの引き換え方法
1. ゲームクライアントからゲームを起動します。
2. 画面上の**ショップ（Shop）**アイコンをクリックします。
3. メニューウィンドウの最下部までスクロールします。
4. 表示された通りにコードを入力欄に入力します。
5. **引き換え（Redeem）**をクリックして報酬を受け取ります。

*（注：プロモーションコードはマイナーパッチやアップデートの後に期限切れになることがあります。開発者の公式SNSやグループページを定期的にチェックし、公開されたらすぐにブーストを受け取りましょう。）*

## よくある質問（FAQ）

### 絶対に見つからない「安全な拠点」を作るにはどうすればいいですか？
100%発見されない拠点は存在しませんが、高い崖の足場や地形オブジェクトの裏、一般的な進行ルートから大きく外れた場所に入口マーカーを配置することで、偶然見つかるリスクをほぼゼロに抑えることができます。

### オフラインの間にペットを盗まれることはありますか？
いいえ。あなたの拠点、マーカー、ペットのコレクションは、現在接続しているアクティブなサーバーセッションに紐付いています。ゲームを退出するとマーカーも消去されるため、別のサーバーに再参加するまでペットは安全に保護されます。

### 侵入者が拠点の中に居座っている（キャンプしている）場合はどうすればいいですか？
敵に入口を見つけられた場合は、すぐに隠れ家に入って排除を試みてください。すでに目立つペットが奪われてしまっていたなら、再度の略奪を防ぐために外のマーカーをマップの全く別のエリアへと移設しましょう。

### 拠点の入口マーカーはどれくらいの頻度で移動させるべきですか？
特に自分のいるエリアで頻繁に他プレイヤーを見かけるようになったら、20〜30分ごとにマーカーの場所を変えるのが賢明です。マーカーの位置を変更することで、前回の隠し場所を把握していたライバルの捜索を振り出しに戻すことができます。
