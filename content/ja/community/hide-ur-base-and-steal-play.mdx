## Hide ur Base and Steal プレイのコアメカニクス

瞬間瞬間のアクションは、ダイナミックなイタチごっこの方式で展開します。誰もがきれいに舗装された通り沿いに専用の区画を持っている一般的な固定型タイクーンとは異なり、このタイトルでは自分の足跡を消すことが求められます。

各ラウンドは、拠点の入り口マーカーを配置する場所を選択することから始まります。一度地面に設置すると、この目立たないポータルは自分だけの地下保管庫（Vault）へと続く唯一の境界線として機能します。保管庫内では、時間の経過とともに継続的に通貨を生み出す不労所得ジェネレーター（主にペット）を購入します。緊張感が走るのは、すべての参加者が対戦相手の拠点マーカーを血眼になって探している共有オーバーワールドへ再び足を踏み入れた瞬間です。

| ゲームシステム | 主な目的 | 主なリスク要因 |
| :--- | :--- | :--- |
| **マーカーの隠蔽** | 他のプレイヤーが見落とすような場所に入り口を設置する | 人通りの多いエリアはすぐに入り口が露呈する |
| **保管庫エコノミー** | ペットを購入・アップグレードして1秒あたりのコイン（CPS）を最大化する | 高ティアのペットは見つかると好戦的なレイダーを引き寄せる |
| **オーバーワールドでの索敵** | 地形の異変を追跡し、プレイヤーが消える瞬間を捉える | マップ移動中に逆アンブッシュ（待ち伏せ）を受けるリスク |
| **保管庫への潜入** | 見つかったマーカーから滑り込み、敵のペットを強奪する | 内部に閉じ込められるか、脱出時に迎撃されるリスク |

コミュニティの報告によると、攻略を成功させるコツは、入り口を実質的に不可視に保ちながら収入の流れを維持することにあります。もし敵にマーカーを発見されれば、予告なしに隠れ家へ侵入され、苦労して資金を投じたペットを奪われてしまいます。

## 戦略的な拠点配置：おすすめの隠し場所

賢い配置は、最も信頼できる第一線の防御となります。開けた野原やスポーン地点の近くにテレポートマーカーを置くのは、数分以内に資産を失う確実な方法です。ベテランプレイヤーは、侵入ポータルをカモフラージュするために、地形のめり込みポイント、影、コントラストの低いジオメトリを探します。

### 保管庫を隠すための最適な地形カテゴリ

*   **草木や茂みの群生:** 生い茂る葉の真下にマーカーを配置することで、ポータルの視覚的な輪郭を崩すことができます。
*   **影の割れ目:** 大きな建造物や崖面の近くにある低照度ゾーンは、自然とマーカーのコントラストを低下させ、暗い地面のテクスチャに溶け込ませます。
*   **高低差のある特殊な地形:** 意図的なパルクールアクションを必要とする高い岩棚や深い渓谷は、平坦な道を進む一般的な偵察者を寄せ付けません。
*   **おとりのルート取り:** 一方向に歩いて尾行を撒き、障害物を回り込んでから入り口を設置します。

| 場所のタイプ | ステルス評価（1〜5） | アクセス難易度 | レイダーの人通り |
| :--- | :--- | :--- | :--- |
| **中央の中庭 / スポーン地点** | 1 / 5 | 極めて簡単 | 非常に多い |
| **開けた草地** | 2 / 5 | 簡単 | 中程度 |
| **崖の岩棚** | 4 / 5 | 難しい（ジャンプが必要） | 少ない |
| **密集した木立ち** | 4.5 / 5 | 普通 | 少ない〜中程度 |
| **隠されたマップの境界線** | 5 / 5 | 難しい | ごくわずか |

コミュニティハブで共有されたプレイヤーの経験則によれば、最も安全な戦略はマーカーの設置場所を定期的に変更することです。熟練のスカウトでサーバーが混雑してきた場合、同じコーナーに15分以上留まるとレイドされるリスクが大幅に高まります。

## レイドの方法：ペット潜入と強盗戦術

レイド（略奪）は、ゲーム内で富を築く最速の道です。無防備なライバルの敷地を見つけて稼ぎ頭のペットを略奪できるのに、なぜ初期資金を稼ぐために何時間も作業を繰り返す必要があるでしょうか？強奪を成功させるには、鋭い偵察力と素早い反射神経が求められます。

```
周囲を偵察  ──>  プレイヤーの不在を確認  ──>  マーカーを突破  ──>  ペットを強奪  ──>  脱出
```

1. **地平線を見渡す:** メニューを開いたりアバターをリセットしたりすることなく、突然姿を消したプレイヤーを探します。彼らは通常、その場所に入り口をマークしています。
2. **周囲の安全を確保:** 拠点の所有者が防衛や逆レイドを狙って近くをうろついていないか確認します。
3. **突破を実行:** マーカーの上を歩いて、相手の内部保管庫に即座に侵入します。
4. **高価値の仲間を狙う:** 最初に目についたコモン生物を掴んではいけません。部屋を見渡して、高い収入を生み出すレアな個体を探します。
5. **安全な場所へダッシュ:** 確保したらすぐに脱出し、被害者がリスポーンしたり追跡してきたりする前に、自分の隠し保管庫に新しい仲間を保管します。

| ペットのティア | 収入倍率 | レアリティ | レイド時のターゲット優先度 |
| :--- | :--- | :--- | :--- |
| **コモン** | 基礎値の1.0倍 | 非常に高い | 拠点が空でない限り無視 |
| **アンコモン** | 基礎値の2.5倍 | 高い | 初期資金が不足しているなら確保 |
| **レア** | 基礎値の5.0倍 | 中程度 | 中級プレイヤーには手堅い収穫 |
| **エピック** | 基礎値の12.0倍 | 低い | 高価値ターゲット。即座に確保 |
| **レジェンダリー / シークレット** | 基礎値の25.0倍以上 | 極めてレア | 最優先ターゲット。即座に脱出 |

プレイヤーの経験談によると、盗んだ戦利品を持って帰還する際は、不規則なパターンで移動することが推奨されます。高ティアのペットを連れていると目立つため、外を巡回している日和見主義のプレイヤーにとって格好の標的になってしまいます。

### 初心者およびベテラン向けのプロのヒント

* **プレイヤーの真後ろを絶対に追跡しない:** 相手が人目につかない隅っこに向かって走っているのを見つけても、距離を保ってください。尾行されていることに気づかれると、あなたが立ち去るまで拠点マーカーの使用を控えてしまいます。
* **保管庫内を散らかさない:** ポータルをくぐった瞬間に、室内に侵入者がいるかどうかが即座に視認できるよう内部を整理整頓しておきましょう。
* **獲得した資金は素早く保管・使用する:** 大量のコインを持ったままオープンワールドを歩き回らないでください。拠点の防御、移動速度のアップグレード、またはより高収入なペットへ即座に再投資しましょう。
* **公式コミュニティグループに参加する:** クリエイターグループのメンバーになると、パッシブ収入の倍率アップやユニークな初期称号などのささやかな特典が与えられることがよくあります。

## よくある質問（FAQ）

### 通常のRobloxタイクーンと比べて Hide ur Base and Steal プレイのユニークな点は何ですか？
従来のタイクーンは、サーバーセッション全体を通じて固定された割り当て区画を特徴としています。対照的に、**hide ur base and steal play**は、プレイヤーの保管庫が動的なポータルによって隠されるステルスサンドボックス要素を導入しており、索敵と拠点防衛がゲームサイクルの中心となっています。

### 拠点の入り口はどのくらいの頻度で移動させるべきですか？
コミュニティの一般的な見解としては、10〜15分ごと、または侵入者が基地に入ってきた直後に必ず入り口マーカーを移動することが推奨されています。位置がバレた場所に入り口を残しておくと、好戦的なプレイヤーからの度重なる襲撃を招くことになります。

### 最も優秀なペットが盗まれた場合はどうすればよいですか？
ペットが盗まれた場合は、外周付近に新しく設置されたマーカーを追跡してください。レイダーは強盗後、盗んだ戦利品を保管するために自分のアジトにすぐ戻ることが多いため、即座に逆レイドを仕掛けるチャンスが生まれます。

### 新しいゲームコードの最新情報を入手するにはどうすればよいですか？
公式のSutik x Tommy Roblox開発者グループに参加し、公式ゲームパッチノートをチェックしてください。新しいコードは通常、サーバーのマイルストーン達成記念、シーズンパッチ、および定期メンテナンスのタイミングで公開されます。
