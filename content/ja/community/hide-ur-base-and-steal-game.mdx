## Hide ur Base and Stealとは？コアゲームプレイループ

開発チーム「Sutik x Tommy」によって制作された本作は、クラシックなRobloxタイクーンの自動進行システムに、かくれんぼのステルス要素と心理戦を融合させたゲームです。マップ全体から見える巨大で派手な要塞を築くのではなく、「見つからないこと」がプレイヤーの最大の目標となります。

```
       [ オープンワールドにスポーン ]
                  │
                  ▼
       [ 拠点のマーカーを隠す ]
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
   [ アジト内部 ]         [ 外部の探索 ]
  • ペットを購入          • 敵の入り口を捜索
  • 放置コインを回収      • ライバルの拠点へ潜入
  • 防衛設備をアップグレード • 上位ペットを強奪
```

プレイヤーには、パブリックワールドの任意の場所に設置できるポータブルな拠点マーカーが与えられます。この入り口を踏むと、個人用の地下シェルターへテレポートします。シェルター内では、購入したペットたちが時間経過とともに通貨を生み出します。そしてシェルターの外に出た瞬間から緊張感が始まります。他のプレイヤーもマップ中をくまなく探し、あなたの入り口マーカーを見つけ出そうとしているからです。もし発見されれば、気づかないうちに侵入され、ペットを盗まれてしまいます。

## 拠点隠蔽の極意：どこにどう隠すか

秘密のマーカーは、あなたの築き上げた帝国の唯一の弱点です。誰もが通る開けた道に堂々と置くのは、泥棒を招待しているようなものです。コミュニティの報告でも、入り口を設置する際は立体的な思考を持つことが強調されています。

```
良い配置:   [ 茂み / 暗い影の中 ] ──> [ 拠点マーカー ] <── 地形の後ろに完全に隠蔽
悪い配置:   [ 開けた通路 ] ───────> [ 拠点マーカー ] <── 走っている全員から丸見え
```

### 最適な場所 vs 危険な場所

| 場所のタイプ | ステルス度 | 人通り | プロのアドバイス |
| :--- | :--- | :--- | :--- |
| **深い茂み・草むら** | 9/10 | 低 | 視線を完全に遮るため、草木モデルの真ん中にマーカーを配置する。 |
| **建物の角の後ろ** | 7/10 | 中 | プレイヤーがカメラアングルを回さずに走り去る場合に非常に有効。 |
| **マップの境界・端** | 8/10 | 極めて低 | 多くのプレイヤーは中央エリアを探すため、外周部は滅多に人が来ない。 |
| **中央スポーン地点周辺** | 1/10 | 極めて高 | 非常に危険。リスポーンしたプレイヤーに数秒で見つかる。 |
| **階段やスロープの下** | 8/10 | 低 | 頭上に遮蔽物があるため、屋根の上から索敵しているプレイヤーに見つからない。 |

### ステルス配置のルール

- **シルエットを消す:** 平坦で開けた場所にマーカーを置いてはいけません。自然の起伏、岩、環境オブジェクトを利用して、入り口マーカーを背景に溶け込ませましょう。
- **周囲を警戒する:** 拠点を設置する際、他のプレイヤーが後ろをついてきていないか、監視されていないかを必ず確認してください。誰かに尾行されている場合は、ダミーの場所に移動してから本命のポータルを置きましょう。
- **見つかったら即移転:** もし侵入者がアジトに入ってきたら、その場所はバレたと考えましょう。脅威を排除したら、すぐにマーカーを回収し、マップの反対側へ再配置してください。

### 効率的にペットを奪う方法

ライバルの拠点を襲撃することは、ショップで正規の価格を支払わずに経済を急成長させる最短ルートです。マップ上でライバルの拠点を捜索する際は、以下の点に注目しましょう：

1. **プレイヤーの動きを観察する:** 岩や茂みの近くでアバターが突然消えた場合、そこに秘密の入り口がある可能性が極めて高いです。
2. **周囲の安全を確認する:** 拠点の持ち主がまだシェルター内にいるか確認します。相手がコインの回収作業中であれば、外へ探索に出かけるのを待ってからマーカーを踏みましょう。
3. **高レアリティを最優先で狙う:** 盗んだアイテムを運ぶ際、インベントリの空き枠には限りがあります。低ティアの初期ペットは無視し、エピックやレジェンダリーへ一直線に向かいましょう。
4. **脱出ルートを確保する:** ペットを掴んでポータルから脱出したら、被害者に追跡される前に、自分の秘密の入り口へ直行して戦利品を安全に保管してください。

## 防衛戦術：拠点を守る方法

攻めの略奪と同じくらい、守りを固めることも重要です。拠点のセキュリティを怠れば、何時間もの進行データが一瞬で奪われてしまいます。

### アジト防衛法の比較

| 防衛手法 | コイン投資 | 効果 | デメリット |
| :--- | :--- | :--- | :--- |
| **徹底的な迷彩（カモフラージュ）** | 0コイン | 高 | 敵の観察眼やマップの明るさに完全に依存する。 |
| **待ち伏せ・迎撃** | 0コイン | 極めて高 | 探索や略奪に出かけず、拠点内で待機する必要がある。 |
| **ダミー誘導** | 低 | 中 | 熟練の泥棒は近くの茂みもくまなくチェックしてくる。 |
| **定期的な拠点移転** | 無料（クールダウンあり） | 高 | サーバー内での自分の位置把握をリセットできる。 |

上級プレイヤーは、60秒間コインを回収してペットの囲いを確認したら、2〜3分間は外に出て索敵するという一定のサイクルを維持することを推奨しています。高価なペットを保管している場合は、アジトを長時間放置してはいけません。

## よくある質問（FAQ）

### hide ur base and steal gameでポータルが見つかるとどうなりますか？
**hide ur base and steal game**で相手にあなたの入り口マーカーが見つかると、相手はそれを踏んであなたのプライベートシェルターに直接侵入できます。侵入者は、あなたが阻止しない限り、配置されているペットを抱え上げて自分の拠点へ持ち帰ることが可能になります。

### 現在使える引き換えコードはありますか？
2026年後半現在、Sutik x Tommyからリリースされた有効なプロモーションコードはありません。ゲーム内のショップメニューにはすでにコード引き換えボックスが実装されているため、今後のアップデートやコミュニティマイルストーンの達成発表をチェックしておきましょう。

### 一度設置した秘密基地のマーカーは移動できますか？
はい。マーカーを回収して別の場所へ再配置することができます。ライバルに自分のお気に入りの隠し場所を覚えられないよう、定期的にマーカーを移動させることは基本的な生存戦略の一つです。

### 初心者が最も速くコインを稼ぐ方法は何ですか？
まずは低コストの初期ペットを購入し、安定したベースラインの収入を確保しましょう。コインの流れができたら、マップの外周部を探索して隠し方の甘い初心者の拠点を見つけ、中ティアのペットを奪って進行を加速させるのがおすすめです。
