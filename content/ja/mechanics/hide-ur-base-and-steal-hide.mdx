## 基本メカニクス：拠点とマーカーの仕組み

本作の基本的なゲームループは、安全な地下アジトを確立することを中心に展開します。地上に巨大でネオン輝く建設区画を確保するのではなく、プレイヤーは自分のアジトを持ち運んで移動します。マーカーを設置すると、地面に目立たないポータル地点が生成されます。このマーカーの上に乗ることで、あなたのアバターは即座に自分専用の地下タイクーンへとテレポートします。

このプライベートな聖域の中では、収益を生み出すペットを購入したり、キャッシュマルチプライヤーを強化したり、集めた資産を保管したりできます。ただし、地上のマーカーは共有オーバーワールド上に物理的に存在し続けます。他のプレイヤーがあなたのマーカーを踏むと、あなたの領域に侵入してコレクションを略奪することが可能です。

| ゲーム内のアクション | システム上の機能 | プレイヤーへの影響 |
| :--- | :--- | :--- |
| **マーカー設置 (Drop Marker)** | 地上フィールドに入り口の当たり判定を展開 | マップと拠点を繋ぐ脆弱な接点を生成 |

このゲームの難しさは、探索と防衛のバランスを取る点にあります。極めて慎重に入り口を配置しない限り、敵の入り口を探し回っている間、常に自分の拠点は無防備な危険にさらされることになります。

## 拠点の隠し場所（Hide Spots）を極める

マーカーを配置するのに最適な場所を見つけられるかどうかが、安定した収入を維持できるか、油断した隙に上位ペットを泥棒に奪われるかの分かれ道となります。熟練プレイヤーは地形クリッピング、影、デコイの挙動を駆使して入り口をカモフラージュします。

**hide ur base and steal hide**の設置場所を決める際は、マーカーを周囲の環境に完全に溶け込ませるか、他のプレイヤーがめったに確認しない場所に置くことを目指しましょう。

### 隠蔽に適したおすすめマップロケーション

1. **茂みや低木の密集地**: マップ上の密集した草木は、入り口ノードのかすかな輪郭を簡単に覆い隠してくれます。
2. **地形メッシュや巨岩の裏側**: 大きな崖の裏側の角は、中央ハブからの直接の視線を遮断します。
3. **高所の足場・レッジ**: 精密なアスレチック（パルクール）が必要な場所は、地面を直線的に走るだけの一般的なプレイヤーをふるい落とせます。
4. **水場や泥のテクスチャ**: マップに濁った地形や水面がある場合、マーカーを水面下に半分沈めることで視認性を大幅に下げられます。

| ロケーションタイプ | ステルス評価 (1-10) | アクセスのしやすさ | 発見されるリスク |
| :--- | :--- | :--- | :--- |
| **中央の通路** | 1/10 | 即時 | 高（即座に略奪される） |
| **密集した木立ち** | 7/10 | 素早い | 中（偶然の接触がある） |
| **崖の裂け目** | 9/10 | ジャンプが必要 | 低（めったに確認されない） |
| **リスポーン地点周辺** | 4/10 | 高い | 高（通行量が非常に多い） |
| **高所のアスレチック足場** | 8.5/10 | 遅い | 極めて低い（パルクールの技術が必要） |

コミュニティハブで共有されているプレイヤーの経験則によると、10〜15分ごとに入り口の隠し場所を変更することで、執拗なハンターに居場所を特定されるのを防ぐことができます。これは特にアクティブプレイヤーが少ないサーバーで効果的です。

## 潜入と略奪：他のプレイヤーの入り口を見つけ出す

レイド（略奪）は、ショップで大量のキャッシュを消費することなくペットの手持ちを増やすための最速のルートです。優秀な泥棒になるには、地面のわずかな異変を見逃さない観察眼を養う必要があります。

ライバルを追跡する際は、何もない空間に突然消え去るプレイヤーや、怪しいランドマークの近くで立ち止まった後に姿を消すプレイヤーに注目してください。適度な距離を保ってプレイヤーを尾行することで、こちらの意図を察知されずに相手の正確な設置ポイントを観察できます。

```
移動中のプレイヤーを発見 -> 距離を維持 -> 消失した座標を記録 -> 密かに接近 -> 拠点に侵入して持ち去る
```

### レイド実行チェックリスト

- **外周を索敵**: 守備重視のビルダーが潜みがちなマップの外縁部を周回する。
- **オブジェクトの死角を確認**: ショップの売店や障害物となる建造物の裏側を覗き込む。
- **色の差異を識別**: マーカーには、周囲の天然の芝生や岩のテクスチャとはわずかに異なるかすかな境界線が表示されることが多い。
- **侵入後は迅速に行動**: ライバルの拠点に入ったら、すぐに最も収益性の高いペットを奪い、所有者がリスポーンまたは帰還する前に脱出する。

| ターゲットペットのレア度 | 目安の強奪所要時間 | 防衛側の脅威レベル | 推奨アクション |
| :--- | :--- | :--- | :--- |
| **コモン / 初期ペット** | 2〜3秒 | ほぼ皆無 | 序盤でなければ無視 |
| **レア** | 3〜5秒 | 低 | 拠点が無人なら回収 |
| **エピック / レジェンダリー** | 5〜8秒 | 高（所有者に通知） | 即座に確保して脱出 |

## 防衛戦略：地下金庫を死守する方法

攻撃は進度を早めますが、リーダーボードのトップに立ち続けるには鉄壁の防御が必要です。**hide ur base and steal hide**の環境を整える際には、略奪を狙う訪問者の脅威を減らすための習慣を身につける必要があります。

相手から視認されている状態でアジトに入ってはいけません。特定の地面を踏んで姿を消したところを目撃されれば、拠点の場所は即座に特定されます。追跡者をマップのあらぬ方向へ誘導したり、スピードブーストがあれば活用したりして、完全に視線を切った状態になってから引き返すようにしましょう。

| 防衛戦術 | メリット | デメリット | 最適な使用タイミング |
| :--- | :--- | :--- | :--- |
| **デコイ徘徊** | ライバルの索敵を混乱させる | 収集効率が落ちる | 怪しいプレイヤーにつけられている時 |
| **定期的な場所変更** | 位置を予測不能に保てる | 手動での再配置が必要 | まとまった資金を確保した後 |
| **即時回収** | 入り口を完全に消去できる | 拠点の収入加算が一時停止 | 長時間のハントに出かける時 |
| **影への潜伏** | マーカーの輪郭を隠せる | 光源の変化で露出しうる | 森林エリアで活動している時 |

コミュニティの報告でも、拠点内に長時間留まり続けることの危険性が指摘されています。メニューを閲覧している最中に侵入者が金庫に落ちてくると、反応する前にペットを奪われて逃走されてしまいます。タイクーンの状況を確認し、収入を回収し、必要なアップグレードを購入したら、速やかに地上へ戻りましょう。

## ペット収集とキャッシュの進行ルート

ペットはこのゲーム体験における経済の柱です。地下の聖域に配置されたペットは、それぞれ受動的にコインを生み出し続けます。生物のレア度が高ければ高いほど、収入の増加スピードは加速します。

新しい卵を購入することと、ライバルの金庫からペットを奪うことのバランスをどのように取るかが、どれだけ早くサーバーを支配できるかの決め手となります。

| 進行段階 | 主な目標 | 収入目安（コイン/秒） | 戦略のポイント |
| :--- | :--- | :--- | :--- |
| **序盤 (Early Game)** | 基本スロットをコモンペットで埋める | 5 - 25 | マップの隅に安全にマーカーを配置 |
| **中盤 (Mid Game)** | レアペットを略奪しスロットを拡張 | 50 - 250 | 隙のあるプレイヤーを積極的にハント |
| **終盤 (Late Game)** | 高倍率のレジェンダリーペットを最大化 | 500+ | 極めて安全な隠蔽と素早いサーバー移動 |

常にバランスの取れたラインナップを心がけましょう。高倍率のペットが数匹いれば莫大な収益が生まれますが、複数のスロットに収入源を分散させておけば、一度の盗難で稼ぎの手段を完全に失ってしまう事態を防ぐことができます。

## よくある質問（FAQ）

### 「hide ur base and steal hide」機能はどのような仕組みですか？
**hide ur base and steal hide**メカニクスは、地上世界に目立たないマーカーを設置し、自分専用の地下タイクーンへのポータルとして機能させるシステムです。設置後、その上に乗ることでペットや資金生成機にアクセスできます。一方、対戦相手はマップを物理的に探し回ってそのポータルを見つけ出し、略奪を試みることになります。

### 他のプレイヤーに一度ですべてのペットを盗まれることはありますか？
いいえ、拠点へのレイドでは通常、侵入者がペットを1匹ずつ掴んで外へ脱出する必要があります。ただし、金庫の確認を怠って入り口を長時間放置していると、侵入者が何度も往復し、保管しているペットを大幅に奪われてしまうリスクがあります。

### 拠点の入り口で誰かが待ち伏せ（キャンプ）している場合はどうすればよいですか？
相手があなたのマーカーを発見して近くに留まっている場合は、絶対に拠点へ入らないでください。マップの別の場所へ移動するか、ツールが使用可能であれば入り口マーカーを回収してください。あるいは別のサーバーに入り直すことで、不利な小競り合いを避けて進行状況を守ることができます。

### ゲームの新しいコードはどこで確認できますか？
新しいコードは、公式のSutik x Tommy Robloxグループページで告知されるほか、大型コンテンツパッチと同時に公開されます。サーバーアップデート後にゲーム内のショップメニューを確認するのが、有効な引き換えコードを見つける最も確実な方法です。
